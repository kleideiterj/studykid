Das HTML-Grundgerüst

Das HTML-Grundgerüst bestimmt mit <html lang="de"> die Sprache der Webseite.

Barrierefreiheit: Screenreader lesen die Sprache der Webseite vor. Die Sprache kann auch für Übersetzungsdienste genutzt werden.

Barrierefreiheit: Das Meta-Viewport-Tag sorgt dafür, dass die Seite auf Handys richtig dargestellt wird.

Quelle: MDN –

Landmarks

Landmarks teilen die Seite in Bereiche. Jedes Element erhält im Accessibility Tree eine Rolle:

<header>
Rolle banner
<nav>
Rolle navigation
<main>
Rolle main
<footer>
Rolle contentinfo

Barrierefreiheit: Screenreader listen die Bereiche auf und springen direkt zum Hauptinhalt. Eine Seite enthält genau ein <main>.

Quelle: MDN – Landmark-Rollen
